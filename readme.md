# ia.doc

Un **agente de IA** es un programa que usa un modelo de inteligencia artificial
para **decidir y ejecutar acciones** con un objetivo, en lugar de solo responder texto.

A diferencia de un chatbot, un agente puede:

- Entender una meta.
- Planificar los pasos para lograrla.
- Usar herramientas (leer archivos, ejecutar comandos, consultar APIs o la web).
- Revisar el resultado y corregir si algo falla.

En resumen: un chatbot conversa; un agente actúa.
